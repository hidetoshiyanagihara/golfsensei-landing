# 週次レビュー・改善の手順（毎週日曜 60 分）

## 0. 準備（数字の記録）

投稿の **24〜48 時間後** に、Instagram アプリで投稿 →「インサイトを見る」を開き、`data/posts_log.csv`（またはスプレッドシートの「投稿実績」シート）に書き写す。

| 列 | アプリでの場所 | 取れない場合 |
|---|---|---|
| 再生数 | リール：再生数／カルーセル：閲覧数 | 空欄（＝未取得） |
| リーチ数 | インサイト「リーチしたアカウント数」 | 空欄 |
| フォロワー外リーチ率(%) | リーチの「フォロワー以外」の割合 | 空欄 |
| 平均視聴時間(秒) | リールのインサイト | 空欄 |
| 視聴維持率(%) | リールの「視聴維持率」グラフ（3 秒時点の値など）。表示されない場合あり | 空欄 |
| いいね・コメント・保存・シェア | インサイト上部のアイコン | 空欄 |
| プロフィールアクセス | 「プロフィールのアクティビティ」 | 空欄 |
| フォロー数 | 「フォロー」（この投稿からフォローされた数） | 空欄 |

- **空欄はそのまま**。0 と空欄は意味が違う（0＝実際にゼロ、空欄＝見ていない／表示されない）
- 数字を書き写す日は「計測日」列に記入（投稿からの経過時間をそろえるため）
- 公式 API でインサイトを自動取得する方法もある（README の「自動取得（任意）」）

## 1. レポートを作る

```bash
python tools/igtool.py report            # 直近 7 日分
python tools/igtool.py report --start 2026-11-16 --end 2026-11-22
```

`reports/weekly_開始日.md` ができる。PC がない場合は Claude Code に「今週のレポートを作って」と頼む。

## 2. レポートを見て考える（6 つの問い）

レポートの末尾に、この 6 つの記入欄がある。**データの表を根拠に**書く。

1. **伸びた投稿の共通点**：フォロー率・シェア率の上位 3 本は、柱・フック型・尺・形式で何が共通しているか
2. **伸びなかった投稿の原因**：下位 3 本は、どの段階で詰まったか（届かない／見られない／動かない／来ない／残らない）
3. **改善すべきポイント**：1 つだけ選ぶ（全部直そうとしない）
4. **次週の企画変更**：カレンダーのどの投稿を、何に差し替えるか
5. **深掘りするテーマ**：当たった型の「続編」を 2〜3 本
6. **廃止する企画**：2 回試してどちらも下位なら廃止

## 3. 判断ルール（迷ったらこれに従う）

| 状況 | 判断 |
|---|---|
| ある柱の投稿が 2 本以上あり、フォロー率がアカウントの中央値の 1.5 倍以上 | **増やす**（翌週の 40% 以上をその柱に） |
| ある型を 2 回試して、2 回ともフォロー率・シェア率が下位 3 割 | **廃止**（`data/improvements.csv` に理由を残す） |
| 再生は上位なのにフォロー率が下位 | **導線を直す**（CTA・プロフィール） |
| 投稿が 2 本未満の柱・型 | **判断しない**（サンプル不足） |
| データが未取得の投稿 | 比較から外す（推測で埋めない） |

## 4. 記録を残す

- 気づき・施策は `data/improvements.csv` に 1 行ずつ（起票日・根拠データ・仮説・施策・結果）
- 新しい企画のタネは `content/ideas_backlog.csv` へ（コメント・質問箱・競合調査から）
- カレンダー（`content/calendar_30days.csv`）の翌週分を差し替える

## 5. Claude Code への頼み方（コピペ用）

```
ig-growth の今週のレポートを作って、docs/07 の6つの問いに答えてください。
数字は data/ の記録だけを使い、未取得は推測しないでください。
そのうえで、来週のカレンダーの差し替え案と、improvements.csv への追記を作ってください。
```

```
ig-growth の content/ideas_backlog.csv から、来週のリール5本の台本を
content/reels/ のテンプレートと同じ形で作ってください。docs/facts.md にない数字は使わないでください。
```

## 6. 月次（30 日目・60 日目・90 日目）

- 目標との差を確認（`report` の「目標ペース」欄）
- [05 の 6 章](05_成長戦略・KPI.md) の見直し手順で、詰まっている段階を特定
- コンセプト・ターゲット・プロフィールを変えるかを決める（変える場合は 03・04 を更新）
