# 使ってよい事実（投稿に書けるのはここにあることだけ）

投稿・台本・キャプションに「実績」「数字」「体験」を書くときは、このファイルにあるものだけを使う。
ここにない数字が必要になったら、**自分で試して測ってから**ここに追記し、それから投稿に使う。
（Claude Code に台本を作らせるときも、このファイルを渡して「ここにない数字は書かない」と指示する）

## 発信者について
- 営業会社（営業代行）の代表。名古屋拠点、全国対応
- 本名・社名をアカウントに出すかは **未決定**（決めたらここに書く）
- 顔出し：**未決定**（初期設定は「顔出しなし・手元と画面のみ」）
- 声出し：**未決定**（初期設定は「テロップのみ。声は任意」）

## AI を仕事で使っている事実（2026-11-08 時点、リポジトリの記録で確認済み）
- 2026-10-23 から、AI に毎朝その日の SNS 投稿（X・Instagram）を作らせ、自動で投稿している
- 2026-10-28 から、YouTube ショートも毎日自動で作って投稿している
- 2026-11-02 から、平日に問い合わせフォームへの営業文の送信を自動化している（送信先は条件で絞り、「営業お断り」の会社には送らない）
- AI に作らせる投稿には「メモにない数字は書かない」「誇大表現をしない」などのルールを渡して守らせている

## 使ってはいけないもの
- 架空の実績・お客様の声・受講者の声
- 測っていない時間短縮（「30分→3分」など）。測ったら上に追記してから使う
- 「AI で月○万円稼げる」など収入を約束する表現
- AI ツールの料金・無料回数・機能制限の具体的な数字（すぐ変わるため。必要なら「投稿日時点」と書き、公式ページで確認してから）
- 他人の投稿・画像・動画・音源の無断使用
