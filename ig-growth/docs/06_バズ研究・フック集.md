# バズる投稿の研究：フック・構成・反応のツボ

人気投稿を真似するのではなく「なぜ伸びたか」を分解し、**このアカウントの場面（仕事・営業）に置き換える**ための資料。
ここにある型は仮説。週次レビューで「当たった型」に印をつけて育てる（`data/posts_log.csv` の「フック型」列で集計される）。

---

## 1. 伸びたリールを分解する 6 つの質問

競合調査や自分の投稿の振り返りで、伸びたリールを見たら次を書き出す（`docs/competitor_research_sheet.csv` にも同じ列がある）。

1. **最初の 1 秒に何が映っていたか**（文字？画面？手元？人？）
2. **テロップの 1 行目は何の型か**（下のフック型のどれか）
3. **「最後まで見る理由」は何だったか**（結果が最後に出る／リストの残り／オチ）
4. **保存する理由は何か**（あとで使う手順・一覧・テンプレ）
5. **送る理由は何か**（「これあの人だ」「チームに共有したい」「笑える」）
6. **コメントが多いなら、何を書きたくなったのか**（自分の体験・反論・質問）

→ その「理由」だけを持ってきて、**自分の場面・自分の言葉・自分の画面**で作り直す。表現や構成をそのまま写さない。

## 2. フック（冒頭 1〜2 秒）の型 15

`フック型` 列にはこの名前を入れる。

| 型 | 中身 | このアカウントでの例 |
|---|---|---|
| 場面直撃 | 視聴者の「その瞬間」を言い当てる | 「上司から『議事録よろしく』って来たら」 |
| 結果先出し | 完成形を最初に見せる | 「この謝罪メール、AIが10秒で書きました」→完成文を表示 |
| 一言だけ | やることが 1 つだけと約束 | 「AIに『角を取って』って言うだけ」 |
| 損失回避 | やると損することを先に言う | 「それ、AIに貼ったらアウトです」 |
| 常識破壊 | 当たり前を否定する | 「Excelの関数、もう覚えなくていいです」 |
| あるある | 共感を取る | 「AIの文章、なんか“AIっぽい”問題」 |
| 比較 | A と B の差を見せる | 「同じ質問、頼み方を変えたらこう変わる」 |
| 実験 | 試してみた | 「AIに“一番嫌なお客さん”をやらせてみた」 |
| 数字 | 具体的な数字（**測った数字だけ**） | 「プロンプトに3行足すだけ」 |
| 質問 | 視聴者に問う | 「AIに会社の資料、そのまま貼ってません？」 |
| 告白・失敗 | 自分の失敗 | 「AIの答えをそのまま送って、やらかしかけた話」 |
| 対象指名 | 誰向けかを名指し | 「営業職の人、商談前にこれだけやって」 |
| 禁止 | 〜しないで | 「AIに『いい感じに』って頼まないで」 |
| 続き物 | 連載の番号 | 「言いにくいメール #3：値上げのお願い」 |
| POV | 主観映像・寸劇 | 「POV：金曜17時に“明日までに資料”と言われた」 |

### フックの作り方のルール
- **テロップ（画面の文字）と音声で同じことを言う**（音なしで見る人が多い）
- 1 行目は **15 字以内**、2 行目で補足
- 最初の 1 秒は **動き**を入れる（画面が切り替わる・文字が出る・手元が動く）
- 「こんにちは」「今日は〜を紹介します」は入れない

## 3. リールの構成テンプレート 5

| 型 | 構成（秒数は 20 秒の場合） | 向いている柱 |
|---|---|---|
| ① コピペ実演 | フック(0-2) → よくある失敗(2-5) → 頼み方を画面で入力(5-12) → 結果(12-17) → 「コピペ用はプロフィール」(17-20) | A・E |
| ② ビフォーアフター | フック(0-2) → 普通の頼み方の結果(2-7) → 一言足した結果(7-15) → 何を足したか(15-18) → CTA(18-20) | A・C・E |
| ③ 寸劇（POV） | 上司/客のチャット(0-3) → 心の声(3-5) → AIに頼む画面(5-13) → 送信して解決(13-17) → 一言(17-20) | B・C |
| ④ 注意喚起 | フック(0-2) → ダメな例を 3 つ(2-12) → 安全な代わり(12-17) → 「チームに送って」(17-20) | D |
| ⑤ 実験 | 何を試すか(0-2) → やってみる(2-15) → 結果と感想(15-20) | B・D |

**共通ルール**
- 尺は 15〜30 秒（最初は 20 秒前後で統一し、尺による差を測る）
- 3 秒に 1 回は画面を変える（テロップ切替・ズーム・カット）
- 最後の 1 秒は冒頭に自然につながる絵にすると、もう一度再生されやすい（ループ）
- 文字は画面中央〜上寄り。下 25% はキャプションと重なる

## 4. 保存・シェア・コメントが起きる理由

| 反応 | 起きる理由 | 企画での作り方 |
|---|---|---|
| 保存 | 「あとで使う」「今は使えないけど必要」 | コピペ用の文面、手順、一覧（○選）、チェックリスト |
| **送信（シェア）** | 「あの人に教えたい」「チームに共有したい」「わかる！と言いたい」 | 言いにくい連絡、情報漏えい注意、職場あるある、上司に見せたい |
| コメント | 「自分の場合を言いたい」「質問したい」「反論したい」 | 二択の問い（「どっち派？」）、「あなたの職場では？」、「○○と書いてくれたら次に作ります」 |
| フォロー | 「この人の次も見たい」「この人にしかない」 | 連載化（#1, #2）、営業のプロの視点、プロフィールの約束 |

## 5. カルーセルの構成（保存される型）

| ページ | 役割 | 書き方 |
|---|---|---|
| 1 枚目 | 表紙 | 連載ラベル＋2 行の大見出し＋「保存して使ってください」 |
| 2〜3 枚目 | 問題提起 | 「こんなことありませんか？」場面 2〜3 個 → なぜ起きるか |
| 4〜7 枚目 | 解決策・具体例 | 1 枚 1 ポイント。プロンプトは「コピペ欄」の枠に入れる |
| 8 枚目 | まとめ | 1 枚でわかる一覧（ここをスクショ・保存される） |
| 最終 | 保存・フォロー誘導 | 「保存して使う」「毎日 1 つ、コピペで使える頼み方」→フォロー |

## 6. 「人気投稿 → 独自企画」変換シート

| 見つけた人気投稿の理由 | そのまま真似すると | このアカウントでの変換 |
|---|---|---|
| 「知らないと損する ChatGPT の機能 5 選」が伸びている（＝一覧＋損失回避） | ツール紹介の焼き直し | 「営業メールで AI に頼む前に入れる 5 つの情報」（一覧＋自分の場面） |
| Excel ショートカットの 1 秒動画が伸びている（＝短い・即効） | 同じショートカット | 「Excel の式を AI に作らせる一言」（短い・即効＋AI） |
| 職場あるある寸劇が伸びている（＝共感・送信） | 同じネタ | 「金曜 17 時の“明日までに”を AI で返す」（共感＋解決） |

## 7. 企画の採点表（投稿前に 1 分で）

| 項目 | 点 |
|---|---|
| 冒頭 1 秒で「自分の場面」とわかるか | /20 |
| 今日すぐ使えるか（コピペできるか） | /20 |
| 誰かに送りたくなる理由があるか | /15 |
| 他のアカウントにない視点（営業・実体験）があるか | /15 |
| 1 本 1 メッセージに絞れているか | /10 |
| 事実だけで書けているか（facts.md） | /10 |
| 最後まで見る理由があるか | /10 |

**70 点未満は作り直す**（トライアルリールで試す実験枠は除く）。
