# 仕事で使うプロンプト集（無料）

> このファイルから、プロフィールのリンク先ページ（https://golfsensei-landing.vercel.app/ai ＝ `output/prompts.html`）が自動で作られます（`python tools/igtool.py render`）。
> 番号はリール・カルーセルで案内している「#番号」と対応しています。新しい投稿を作ったら、ここに追加してから投稿してください。書式は「### #番号 タイトル」の下にコードブロック。

## 仕事で使うプロンプト集

Instagram「（アカウント名）」で紹介した、仕事で使える AI の頼み方をまとめています。
（　）の部分を自分の内容に変えて、ChatGPT・Gemini・Claude・Copilot など、お使いの AI に貼ってください。無料版で使えるものだけです。

**使う前に（大事）**
- お客さんの名前・連絡先、社外秘の数字、パスワードは入れないでください。使うときは [A社] [金額] のように置き換えてから（#02）
- AI の答えは毎回少しずつ変わります。数字・日付・名前は、送る前に自分で確認してください（#08）
- 会社に AI の利用ルールがある場合は、そちらに従ってください

最終更新：（日付を入れる）

### #00 頼み方の基本テンプレート
```
あなたは（役割）です。
（相手）に向けて、（作りたいもの）を作ってください。
目的：（読んだ人にしてほしいこと）
材料：（メモや情報を貼る）
条件：（文字数・口調・してほしくないこと）
形式：（箇条書き／表／メールなど）
足りない情報があれば、作る前に質問してください。
```

### #01 お礼メール（相手と目的を入れる）
```
取引先へのお礼メールを書いてください。
相手：（例：昨日はじめて商談した会社の部長）
目的：（例：次回の打ち合わせ日程を決めたい）
条件：200字以内、かしこまりすぎない
```

### #02 置き換えた文章をそのまま整える
```
以下の文章では、会社名を[A社]、人の名前を[担当者]、金額を[金額]に置き換えています。
記号はそのまま残して、取引先に送るメールの形に整えてください。

（ここに置き換え済みの文章）
```
※送る前に、記号を本当の名前・金額に戻してください。

### #03 会議のメモから議事録
```
以下は会議のメモです。議事録にしてください。

形式：
1. 決まったこと（箇条書き）
2. やること（表：誰が／いつまでに／何を）
3. 次回までに確認すること

ルール：
・メモに書いていないことは付け足さない
・担当や期限が分からないものは「要確認」と書く

（ここにメモを貼る）
```

### #04 言いにくいメールの「角を取る」
```
次の文章を、取引先に送るメールにしてください。
言いたいことは変えずに、角を取ってください。
相手が次にどうすればいいか（何を決めればいいか）が分かる一文を入れてください。
150字以内でお願いします。

（ここに本音の文章）
```

### #05 商談前5分の準備
```
これから、以下の会社と初めて商談します。私は（自社の商品・サービス）の営業です。
会社の紹介文を貼るので、次の3つを出してください。

1. この会社が今困っていそうなこと（3つ）
2. 最初に聞くと話が広がる質問（5つ）
3. 初回の商談では言わない方がいいこと（2つ）

紹介文から読み取れないことは「推測」と書いてください。

（ここに相手の会社紹介文を貼る ※公開されている情報だけ）
```

### #06 Excel の式を作ってもらう
```
Excelで、（どの列）に（何のデータ）が入っています。
（どの列）に（何を）表示したいです。
（どのセル）に入れる式を教えてください。式の意味も一言で説明してください。
うまく動かないときは、エラーの文言を貼るので直し方を教えてください。
```

### #07 返事が来ないときの催促メール
```
1週間前に送った（見積もり／資料／日程の候補）の返事が来ていません。
相手を責めずに、返事をもらいやすい催促メールを書いてください。

条件：
・相手が「はい」か「いいえ」だけで返せる質問を1つ入れる
　（例：「今月中のご判断は難しそうでしょうか？」）
・こちらの都合ではなく、相手の手間が減る書き方にする
・150字以内
```

### #08 AI の答えを送る前のチェック
```
今の回答について、次の2つを教えてください。
1. 間違っている可能性がある所と、その理由
2. 私が自分で確認すべき所（数字・日付・固有名詞・制度など）
確信が持てない所は、はっきり「確信がない」と書いてください。
```

### #09 何を頼めばいいか分からないとき
```
（作りたいもの：例 社内向けの新サービス企画書）を作りたいです。
いいものにするために足りない情報があれば、作る前に私に質問してください。
質問は5つまで、1つずつ番号をつけてください。
私が答えたら、それをもとに作ってください。
```

### #10 「嫌なお客さん」役で営業の練習
```
あなたは、営業電話が大嫌いな中小企業の社長です。忙しく、知らない会社からの電話にはすぐ断ろうとします。
私がこれから営業の電話をかけるので、本物の社長のように冷たく、短く返してください。
・1回の返事は1〜2文
・私の話に興味を持てる理由があれば、少しだけ話を聞いてください
・私が「終了」と送ったら役をやめて、私の話し方の「良かった点」と「直す点」を3つずつ教えてください
```

### #11 長いメールを3行に
```
次のメールを3行で要約してください。
1行目：結論（相手が求めていること）
2行目：理由・背景
3行目：私が次にやること

（ここにメールを貼る）
```

### #12 メモから日報
```
次のメモを日報にしてください。
形式：今日やったこと／分かったこと／明日やること
メモにないことは書かないでください。

（ここにメモを貼る）
```

### #13 言い訳しない謝罪メール
```
（相手）への謝罪メールを書いてください。
起きたこと：（事実）
構成：お詫び→事実→原因→対策→今後の連絡
言い訳に聞こえる表現は使わず、200字以内で。
```

### #14 次につながる断りメール
```
（依頼の内容）を断るメールを書いてください。
断る理由：（理由）
関係は続けたいので、代わりにできること（例：時期をずらす・一部なら可能）を1つ入れてください。
```

### #15 上司への報告を結論から
```
次の内容を上司への報告にしてください。
1行目に結論、次に理由、最後に相談したいこと。全体で5行以内。

（ここに状況のメモを貼る）
```

### #16 アイデアを10個出して選ぶ
```
（テーマ）のアイデアを10個出してください。
それぞれ「実現しやすさ」と「効果」を高・中・低で評価し、表にしてください。
最後におすすめを2つ選んで理由を書いてください。
```

### #17 プレゼン前の想定質問
```
次の資料を（相手：例 役員）に説明します。
聞かれそうな質問を5つと、それぞれの短い答え方を出してください。
答えられない質問は「要確認」と書いてください。

（ここに資料の要点を貼る）
```

### #18 硬い文章をやわらかく（またはその逆）
```
次の文章を、意味は変えずに（社内チャット向けにやわらかく／取引先向けに丁寧に）書き直してください。
長さは今と同じくらいで。

（ここに文章を貼る）
```

### #19 会議のアジェンダ
```
（会議の目的）のための（時間：例 30分）の会議のアジェンダを作ってください。

```

### #20 箇条書きからスライド構成
```
次の箇条書きを、（枚数）枚のスライド構成にしてください。
各スライドに「タイトル」と「言いたいこと1文」をつけてください。

（ここに箇条書きを貼る）
```

### #21 値上げのお願い
```
（相手）に、（商品・サービス）の価格改定をお願いするメールを書いてください。
改定の時期：（いつから）
理由：（例：仕入れ価格の上昇）
これまでの感謝を最初に伝え、相手が社内で説明しやすいように理由を短く具体的に書いてください。
質問や相談の窓口があることも伝えてください。
```

### #22 日程調整メール（候補を3つ）
```
（相手）との打ち合わせの日程調整メールを書いてください。
候補：（日時1）（日時2）（日時3）
所要時間：（例：30分）／方法：（オンライン・訪問）
相手が番号で返せるように、候補に番号をつけてください。100字程度で。
```

### #23 クレームへの最初の返信
```
お客様から次のお問い合わせ（苦情）が届きました。最初の返信を書いてください。
・まず不快な思いをさせたことにお詫びする
・事実がまだ確認できていないことは約束しない
・いつまでに、何を確認して連絡するかを書く

（ここにお問い合わせの内容 ※名前・連絡先は消して）
```

### #24 提案書の骨子
```
（相手の会社の業種）に（自社の商品・サービス）を提案します。
相手の課題：（分かっていること）
提案書の骨子を、表紙を除いて6枚以内で作ってください。
各ページに「タイトル」と「伝えること1文」をつけてください。
足りない情報があれば、作る前に質問してください。
```

### #25 アンケートの自由回答を分類
```
次のアンケートの自由回答を、内容ごとに分類してください。
形式：表（分類名／件数／代表的な回答1つ）
最後に、件数が多い順に「すぐ対応できそうなこと」を3つ挙げてください。

（ここに回答を貼る ※名前などは消して）
```

### #26 Excel の作業を手順にしてもらう
```
Excelで、毎回手作業で（やっている作業）をしています。
（表の構成：例 A列に日付、B列に担当者、C列に金額）
この作業を早くする方法を、関数・並べ替え・フィルターなど、Excelの標準機能だけで教えてください。
手順は番号つきで、初心者にも分かるように。
```

### #27 断られた後のフォローメール
```
（相手）から、今回は見送りと連絡がありました。
関係は続けたいので、次の点を入れたお礼のメールを書いてください。
・検討してくれたことへのお礼
・押し付けにならない、今後に役立つ情報を1つ（例：（情報））
・次に連絡してもいい時期を相手に選んでもらう一文
150字以内で。
```

### #28 営業用の自己紹介文
```
初めての相手に送る、営業用の自己紹介文を書いてください。
私の仕事：（何をしているか）
相手にとっての良いこと：（例：〇〇の手間が減る）
条件：3文以内、売り込み感を出さない、最後は質問で終える
```

### #29 敬語のチェック
```
次の文章の敬語をチェックしてください。
間違っている所・不自然な所を表にして（元の表現／直した表現／理由）、最後に直した全文を出してください。

（ここに文章を貼る）
```

```

「急ぎ×大事」の4つに分けて表にし、月〜金に割り振った計画を作ってください。

（ここにタスクを貼る）
```

### #31 「お手本」を見せて口調をそろえる
```
次の「お手本」と同じ口調・長さで、（作りたいもの）を書いてください。
お手本：
（自分が過去に書いた文章を1つ貼る ※名前などは置き換えて）
今回伝えたいこと：（内容）
```

### #32 AIに「ダメ出し」してもらう
```
あなたは厳しいけれど面倒見のいい上司です。
次の文章を（読む人：例 取引先の部長）が読む前提で、ダメ出ししてください。
・分かりにくい所、失礼に見える所、長すぎる所を表に（場所／理由／直し方）
・最後に直した全文

（ここに文章を貼る）
```

### #33 よくある断り文句と返し方を準備する
```
私は（商品・サービス）の営業です。相手は（業種・役職）です。
初回の商談で言われそうな断り文句を5つと、
それぞれに「押し売りにならない返し方」を1つずつ出してください。
返し方は、相手の事情を聞く質問で終わるようにしてください。
```

### #34 比べるときは「表で」
```
（AとB：例 2つのツール／2つのプラン）を比べたいです。
比べる観点を5つ挙げて、表にしてください。
分からない項目は「要確認」と書き、最後に「どんな人にどちらが向くか」を1行ずつ書いてください。
```
