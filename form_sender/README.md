# 問い合わせフォーム営業ツール（名古屋市 建設・設備・リフォーム・不動産）

Python + Playwright。リスト作成 → 送信前チェック → フォーム入力 → 送信 → 記録 までを 1 つのツールで行います。

## SaaS向け 自動営業（2026-10-28〜。いまはこちらを使う）

GitHub Actions（`.github/workflows/form_sales.yml`）が平日10:13に自動で動きます。1回の流れ：

1. **送り先を探す**（`ai.discover`）：未処理の候補が15社未満なら、Claude の Web検索で「中小企業向けの国内SaaS・社員10〜100名程度」を探す。
   切り口（資金調達直後／営業・IS募集中／業界特化／バックオフィス／店舗向け／新サービス）を毎回変える。上場・大企業・同業（営業代行など）は除く
2. **送れるか確かめる**（`form_engine.precheck`）：フォームなし・営業お断り・画像認証は、AIで調べる前に外す
3. **事前調査**（`ai.research`）：公式サイト＋Web検索で、何を誰に売っているか／会社の段階／営業・集客体制／競合とその売り方／合う営業代行 を出典つきでメモ
4. **判断と営業文**（`ai.write`）：対象外（BtoC・大企業向け・上場・同業など）なら送らない。送る場合は、その会社の事実と競合の中での強みに触れ、
   どんなアポ獲得が合うかを書いた本文（150〜480字）と件名を作る。実績・料金・保証・誇大表現・URLは書かせない（`ai.BANNED` で検査し、違反は書き直し）
5. **送信**：`message_saas.txt`（宛名・自己紹介・無料リスト20件・結び・連絡先）に本文を入れて送る。1回最大10件（`config.SAAS_SEND_PER_RUN`）

- 本番の送信は `form_sender/LIVE_ON` があるときだけ行う（テストで文面と入力を確かめてから置く）
- **AIのクレジットは自動投稿を優先する方針（2026-10-29）**。テスト実行や `LIVE_ON` を置く前に、かかる費用を柳原さんに伝えて了承をもらう
- 手動実行：Actions → Form sales (SaaS) → Run workflow（mode=test で入力まで・送らない）
- **リポジトリが公開のため**、送り先・調査メモ・文面・結果は `state.enc`（鍵は Secrets の `FORM_STATE_KEY`。柳原さんが決めた合言葉）に暗号化して保存し、ログには会社名を出さない。
  手元で見るとき：`FORM_STATE_KEY=… python vault.py open` → `companies.csv` / `research.jsonl` / `result.csv`
- テスト：`python tests/run_saas.py`（AIは差し替え、送信先はローカルの疑似サイトのみ）
- 費用の目安：Claude（`claude-opus-5-5`）＋Web検索で 1社の調査・文面 約50円、送り先探し 1回 約50円（平日10件送ると月1〜1.5万円ほど。`FORM_AI_MODEL=claude-sonnet-5-5` でおよそ半分）

## セットアップ

```bash
cd form_sender
pip install -r requirements.txt
playwright install chromium
```

## 使い方

```bash
# 1. リスト作成（検索エンジンから。1回最大100社、既存の会社は追加しない）
python main.py collect

# 1'. 企業名簿CSVを取り込む場合（列: 社名, 所在地, 業種, URL ※URLが空なら検索で公式サイトを特定）
python main.py import 名簿.csv

# 2. テストモード（入力のみ・送信しない・スクリーンショット保存）。既定10件
python main.py send --mode test
python main.py send --mode test --headed        # ブラウザを表示して確認
python main.py send --mode test --no-wait       # 待機なしで確認（テストのみ可）
python main.py send --mode test --retest        # テスト済みの会社も再テスト

# 3. 本番モード（実際に送信。実行前に yes の確認あり。1日最大50件）
python main.py send --mode live
python main.py send --mode live --count 20

# 件数確認
python main.py status
```

テストモードでは、入力後の画面が `screenshots/` に保存されます。
本番に移る前に、スクリーンショットで各欄に正しく入っているか必ず確認してください。

## ファイル

| ファイル | 内容 |
|---|---|
| `companies.csv` | 送信先リスト（社名, URL, 所在地, 業種）。手で追加・削除しても可 |
| `ng_list.csv` | 送らない会社（社名 または URL のどちらかで一致） |
| `message.txt` | 本文。`{社名}` は送信先の社名に置換 |
| `result.csv` | 結果記録（社名, URL, 結果[成功/スキップ/失敗], 理由, 日時, モード） |
| `config.py` | 送信者情報・件数上限・待機秒数・判定キーワード |
| `screenshots/` | テスト入力後／本番送信後の画面 |

`result.csv` には指定の5列に加えて「モード（テスト/本番）」列があります。
テストの記録を送信済みと誤認しないためです。

## 動作仕様

### 1. リスト作成（`collect.py`）
- 名古屋市16区 × 業種（建設・工務店・空調/給排水/電気設備工事・リフォーム・不動産）で検索（DuckDuckGo → 取れなければ Bing）
- ポータル・求人・SNS など公式サイト以外のドメインは除外（`config.EXCLUDED_DOMAINS`）
- 会社概要ページを読み、次の会社は除外:
  名古屋市の所在地が無い／上場の記載（東証・証券コード・IR情報 など）／大手社名（`LARGE_COMPANY_NAMES`）／
  従業員数が100名超／資本金3億円以上
- 従業員数が判明した会社を先頭に書き込み（＝送信時に優先）
- 社名・ドメインで重複判定。前回の検索の続きから再開（`.collect_state.json`）

### 2. 送信前チェック（該当したら送らずスキップ）
- 問い合わせフォームが見つからない（トップのリンク・よくあるパス・iframe埋め込みを探索）
- 「営業お断り」「セールスお断り」「営業目的のお問い合わせはご遠慮」等の記載
  （「営業時間外のお電話はご遠慮」などは誤検知しないよう除外）
- reCAPTCHA / hCaptcha / Turnstile / 画像認証（回避はしません。見えない reCAPTCHA v3 もスキップ）
- 送信済みの会社、`ng_list.csv` の会社
- 埋められない必須欄がある／問い合わせ種別に「その他」等が無い／本文が文字数制限を超える

### 3. 入力
姓名・ふりがなの分割欄、カタカナ指定、電話番号の3分割、郵便番号・電話の「ハイフンなし」指定、
都道府県プルダウン、住所の分割、確認用メール、同意チェック、問い合わせ種別（「その他」優先）に対応。
会社名欄に文字数制限がある場合は「AXION SALES」を入力。

### 4. 送信と記録
- 確認画面がある場合は「送信する」まで進め、完了表示（ありがとうございました／送信完了 等）や
  完了ページへの遷移、Contact Form 7 の送信状態で成功を判定
- 送信ボタン後に完了を確認できなかった場合は「失敗（送信後: …送信された可能性あり）」と記録し、**再送しません**
- 1件ごとに30〜120秒ランダムに待機、本番は1日最大50件（`result.csv` の当日分で判定）

## 動作確認（ローカルの疑似サイト）

```bash
python tests/run_e2e.py
```

127.0.0.x 上の疑似サイト（表形式／div形式フォーム、確認画面、Ajax送信、営業お断り、reCAPTCHA、
フォーム無し、埋められない必須欄）でリスト作成〜テスト〜本番送信までを検証します。実在の会社にはアクセスしません。
（Playwright 付属ブラウザ以外を使う場合は `CHROMIUM_PATH=/path/to/chrome` を指定）

## 注意

- 実在サイトはフォームの作りが様々です。必ずテストモードでスクリーンショットを確認してから本番を実行してください。
- 本文に記載のとおり、返信で「不要」と言われた会社は `ng_list.csv` に追加してください。
- 検索エンジンは短時間に大量アクセスするとブロックされることがあります（連続5回結果が取れないと自動で中断）。
  その場合は時間を空けるか、`import` で名簿CSVから取り込んでください。
