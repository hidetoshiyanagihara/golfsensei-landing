# AI CEO COMMAND CENTER

AI CEO PROJECT（代表：柳原）の管理画面です。**ONE HUMAN. MANY AI EMPLOYEES.**

売上・利益・予算・AI社員・事業アイデア・商品・SNS投稿・経営会議を1か所で管理します。

> **スマホから使う**：Netlify ＋ Turso（どちらも無料）で公開できます。手順は [docs/DEPLOY.md](docs/DEPLOY.md)。
>
> **いまの段階：PHASE 1（基盤）完了**。AI社員は「登録のみ・未接続」で、AIは一切実行されません（費用0円）。
> 何ができて何ができないかは [docs/ROADMAP.md](docs/ROADMAP.md) を見てください。

## 起動方法（自分のパソコンで動かす）

必要なもの：Node.js 20.11 以上（22 推奨）。ターミナルで、このフォルダ（`ai-ceo-project`）に移動してから実行します。

```bash
# 1. 初回だけ
npm install
npm run setup        # ログイン用パスワードが表示されます（.env.local に保存）
npm run db:init      # データベースを作り、AI社員7名・最初の商品計画・目標を登録
npm run db:import    # SNS自動投稿（axion-autopost）の結果を実データとして取り込む

# 2. 毎回
npm run dev
```

ブラウザで **http://localhost:3100** を開き、`npm run setup` で表示されたパスワードでログインします。
パスワードを忘れたら `.env.local` の `ADMIN_PASSWORD=` の行を見てください（書き換えれば変更できます。変更後は `npm run dev` をやり直す）。

### 画面確認用のサンプルデータ（任意）

```bash
npm run db:sample        # 架空のデータを入れる（data_kind='sample'）
npm run db:sample:clear  # 消す
```

サンプルは、画面右上の「サンプル表示」をONにしたときだけ見えます。**実データの集計・経営会議には絶対に混ざりません。**

### SNS自動投稿の最新結果を取り込み直す

`git pull` で最新の `axion-autopost/posts/` を取ってから `npm run db:import`。何度実行しても重複しません。

## 大事なルール（このリポジトリは公開されています）

- **`data/`（売上・顧客などのデータベース）と `.env.local`（パスワード）は Git に入りません。** 絶対に `git add -f` しないでください。
- 管理画面のソースは Vercel の静的配信から除外しています（リポジトリ直下の `.vercelignore`）。既存の LP・自動投稿・フォーム営業には一切影響しません。
- 顧客の氏名・メールアドレスなどの個人情報は、PHASE 1 では保存しない設計です（問い合わせは「要約」だけ）。
- AIの判断ルールは [knowledge/policies/operating-rules.md](knowledge/policies/operating-rules.md)。
