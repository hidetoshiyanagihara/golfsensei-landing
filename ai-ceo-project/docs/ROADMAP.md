### 当初の計画（参考）

- ⬜ Anthropic API 接続（`@anthropic-ai/sdk`、サーバー側のみ。キーは `.env.local`）
- ⬜ 実行のたびに：予算ガード → 実行 → トークン数から費用を推計 → `agent_runs` に「AIの判断」と「実際の結果」を分けて保存 → 上限超過なら自動停止
- ⬜ 最初は **代表者がボタンを押したときだけ実行**（自動実行は後）
- ⬜ AI CEO：ルールベースの経営会議を読み、文章での分析・提案を追加
- ⬜ 市場調査AI：Web検索で調査し、情報源URL・調査日・事実/推測付きで事業アイデアを登録
- ⬜ 商品開発AI・マーケティングAI（下書きまで）・財務分析AI

**要相談（代表者の判断が必要）**
- APIキーの準備（既存の自動投稿とは別のキーにすると費用を分けて見られます）
- 月の上限額（初期値：AI API 1万円／月、AI社員ごとに1,000〜3,000円）
- 使用モデル（初期値は Claude Opus 5.5。費用を下げたい場合は Sonnet 5.5 / Haiku 5.5 に変更可能。品質とのバランスは代表者が決める）
